# S07 - The secondary repository stopped three days ago

Fictitious company: Cartiera Valdora S.p.A. - synthetic data only. **Failure reproduced.** For three nights the backup_b step is logged as ok and does nothing. The primary repository is current; the newest snapshot of the secondary is 72 hours behind, against a limit of 26 hours written in the policy. **Pass criterion.** Verdict ALERT, exit code 1, finding repo_b_stale on repo_b and its newest snapshot; the alert carries as_of, the lag in hours and what the job log claimed; the primary drill is ok; the console does not print RUN OK. **Lesson.** The repository is read, not the log that talks about it; an alert without its as_of is not an alert. Run it from this folder with `python check.py` (exit code 0 means the scenario passed; the checker needs no argument, no environment variable and no network) and read the detail in `build/scenarios/S07/result.json`.
