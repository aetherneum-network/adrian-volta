# S09 - Host off at night across the daylight-saving change

Fictitious company: Vetreria Altofonte S.r.l. - synthetic data only. **Failure reproduced.** The host is off from 23 October 20:00Z to 25 October 04:00Z, the night the clocks go back. The schedule is 00:30 UTC. A twin instance writes the same schedule as 02:30 Europe/Rome. **Pass criterion.** UTC schedule: verdict ALERT, exit code 1, two windows missed, one declared catch-up run that recovers the latest window while the earlier one stays recorded as missed, every timestamp in the report ends in Z. Local-time schedule: tz_mixed, windows not evaluated, no window and no catch-up guessed. **Lesson.** Scheduled work lives in UTC; a catch-up is one run and is declared; a local time is not converted by guesswork. Run it from this folder with `python check.py` (exit code 0 means the scenario passed; the checker needs no argument, no environment variable and no network) and read the detail in `build/scenarios/S09/result.json`.
