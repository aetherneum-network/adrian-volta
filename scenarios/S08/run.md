# S08 - Backup before export

Fictitious company: Molino Serrabruna S.r.l. - synthetic data only. **Failure reproduced.** The policy lists backup_a before export, so every night the snapshot holds the export of the day before. The same nights are replayed with the chain in order. **Pass criterion.** Inverted: verdict FAILED, exit code 3, one finding on policy/backup.yaml / chain; the drill differs on the export file only and the snapshot's export has yesterday's SHA-256. Chained: verdict OK and the snapshot's export has today's SHA-256. **Lesson.** One chained runner, in order: a backup taken before the export is a backup of yesterday. Run it from this folder with `python check.py` (exit code 0 means the scenario passed; the checker needs no argument, no environment variable and no network) and read the detail in `build/scenarios/S08/result.json`.
