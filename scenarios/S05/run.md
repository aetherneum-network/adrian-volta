# S05 - Backup and restore of a tree with long paths and accented names

Fictitious company: Molino Serrabruna S.r.l. - synthetic data only. **Failure reproduced.** Eleven files, two of them with relative paths longer than 260 characters, several with accented names, one empty; two nights of the chain, then a restore drill of the newest snapshot. **Pass criterion.** Verdict OK, exit code 0; source count = count declared by the snapshot = restored count; every restored file re-hashed here has the SHA-256 of its source; an independent reference finds no differing file in either repository. **Lesson.** A restore is verified against the source manifest, file by file, or it is not verified. Run it from this folder with `python check.py` (exit code 0 means the scenario passed; the checker needs no argument, no environment variable and no network) and read the detail in `build/scenarios/S05/result.json`.
