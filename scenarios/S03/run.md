# S03 - An admin service must not become public (negative: the pack must refuse)

Fictitious company: Vetreria Altofonte S.r.l. - synthetic data only. **Failure reproduced.** Two ways to put an admin service on the public plane: a router that lists both entrypoints (routes/registry.yaml), and an admin service attached to the public network (topology.yaml). **Pass criterion.** Both are refused: verdict BLOCKED, exit code 2, the finding names the file and the item that draw the edge, the accepted table contains zero admin-public edges, and an independent reference computes the same edge on the table as loaded. **Lesson.** The admin plane is a property of the table that is checked, not a convention that is remembered. Run it from this folder with `python check.py` (exit code 0 means the scenario passed; the checker needs no argument, no environment variable and no network) and read the detail in `build/scenarios/S03/result.json`.
