# S02 - Forty-one routes and one forgotten copy

Fictitious company: Molino Serrabruna S.r.l. - synthetic data only. **Failure reproduced.** Fourteen services, forty-one routers, and a copy of the shop route left in routes/archive-2025/ with another router name and a higher priority. The file provider loads sub-folders too, so the copy would win silently. **Pass criterion.** Verdict BLOCKED, exit code 2, exactly one finding that names both files; 42 entries as loaded, table not accepted, no finding on the other forty routes. With the copy set aside the same tree is accepted with 41 entries. **Lesson.** A recursive provider loads what was forgotten; the lint names both files instead of picking a winner. Run it from this folder with `python check.py` (exit code 0 means the scenario passed; the checker needs no argument, no environment variable and no network) and read the detail in `build/scenarios/S02/result.json`.
